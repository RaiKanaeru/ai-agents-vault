# Effective Obsidian Workflow

## PARA & CODE Architecture
- **Capture**: Ingest raw technical notes into `50-Knowledge/_Raw/`.
- **Organize**: Structure notes by concept, bugfix, or pattern.
- **Distill**: Summarize core root causes and atomic fixes.
- **Express**: Link notes together with MOCs (Maps of Content) and project trackers in `20-Projects/`.

## Backup Strategy
- Vault is version-controlled via Git and synced to GitHub remote repository.
- Use `sync-vault.bat` or the Obsidian Git plugin for auto-backups.
