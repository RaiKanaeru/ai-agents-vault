# Agent Operating Rules

## Memory & Vault Structure
- Obsidian Root: `D:\Obsidian\AI-Agents`
- Directory Taxonomy:
  - `10-Agents`: Core agent profiles, operating rules, workflow guidelines.
  - `20-Projects`: Long-term project logs and architecture notes.
  - `50-Knowledge`: Modular documentation categorized into `Bugfixes`, `Concepts`, `Commands`, `Patterns`, `_Raw`.
  - `99-Session-Logs`: Ephemeral or date-stamped session retrospectives.

## Security
- Strictly avoid saving raw API keys, session cookies, database credentials, or secret env vars into the vault.
